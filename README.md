# برنامج تذاكر العيادة (Sunmi V2)

## طريقة بناء الـ APK
1. ثبّت Android Studio (نسخة حديثة) وافتح مجلد المشروع `ClinicTickets`.
2. انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. من القائمة: Build ‹ Build Bundle(s) / APK(s) ‹ Build APK(s).
4. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## التثبيت على Sunmi V2
- انسخ الـ APK للجهاز وثبّته، أو فعّل USB debugging وشغّله من Android Studio مباشرة.

## ملاحظات
- الطباعة بتتم كصورة عشان العربي يطلع سليم؛ جرّب "طباعة تذكرة تجريبية" من الإعدادات أول ما تثبت.
- النداء الصوتي يحتاج صوت عربي مثبت في الجهاز (Text-to-Speech)، ولو غير موجود يشتغل البرنامج بدون صوت.
- البيانات محفوظة محلياً على الجهاز (SQLite)، والترقيم يبدأ من 1 كل يوم، والسجل القديم يفضل محفوظ.
- لا يتم تسجيل أي بيانات للمرضى، فقط رقم التذكرة ونوعها وأوقاتها.
